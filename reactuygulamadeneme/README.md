# Sayaç Uygulaması (React + Vite)

Bu repo basit bir sayaç uygulaması içerir. Proje React ve Vite kullanılarak hazırlanmıştır.

Ne var içinde?
- src/App.jsx: Basit arttır/azalt sayaç komponenti
- src/App.css: Stil dosyası

Nasıl çalıştırırsın (yerelde):
1. npm install
2. npm run dev

Not: Bu proje öğrenci işi tarzında, öğrenmek için hızlıca yapılmış bir örnektir. Kod basit ve anlaşılır tutuldu. Keyifli öğrenmeler! 🚀

Yapıldı: React ile yazıldı — öğrenci diliyle anlatmaya çalıştım, takıldığın yerde haber ver.
